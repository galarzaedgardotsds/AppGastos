# Edgar Finanzas PRO 💎

Aplicación web progresiva (PWA) de finanzas personales y control de gastos desarrollada por Edgar.

## Características
- 📱 **PWA Offline:** Se instala directamente desde el navegador en Android / iPhone y funciona sin conexión.
- 🔒 **Seguridad con PIN:** Bloqueo de 4 dígitos para proteger tu privacidad.
- 💳 **Compras en Cuotas:** Agendamiento y proyección automática mes a mes de cuotas con tarjeta de crédito.
- 🔁 **Gastos Fijos / Recurrentes:** Registro automático de suscripciones mensuales (Spotify, alquiler, servicios).
- 🎯 **Metas de Ahorro:** Alcancía virtual con barra de progreso.
- 📊 **Gráficos Interactivos:** Análisis por categoría en tiempo real con Chart.js.
- 📸 **Fotos de Comprobantes:** Adjuntá fotos de tickets y facturas.
- 🧮 **Calculadora Rápida:** Ingreso con operaciones aritméticas directas (ej: `1500+2300`).
- 💾 **Exportación y Respaldo:** Descarga en Excel (CSV) y copia de seguridad en JSON.
